# README images

Screenshots and clips used by the repository's own `README.md`.

They live here rather than alongside the product shots in
`apps/site/public/screenshots/` because Vite copies everything under a
`public/` directory into the showcase site's build output. An animation
parked there would be downloaded by every visitor to the site without
ever being shown to them.

Keep these small. A README image is cloned by everyone who clones the
repository, forever, and it is never removed from git history by
deleting it later. Crop tightly, and prefer the smallest thing that
makes the point over a full-page capture.
